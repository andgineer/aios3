# aioS3

Файлоподобный интерфейс для AWS S3 с aiobotocore.

## Что есть

- `stream()` — файлоподобный объект для чтения по частям
- `read()` — чтение всего файла как bytes
- `chunks()` — асинхронный генератор частей файла
- `save()` — запись bytes в S3

## Зачем

Использование с файлоподобными операциями (`pickle.load()`, `json.load()` и т.д.) на объектах S3 без загрузки целых файлов в память.

[Подробная статья в блоге](https://sorokin.engineer/posts/ru/aws_s3_chunks_async.html)
